# Mansur DevOps Project

Мой учебный DevOps-проект, который я собираю с нуля на Ubuntu Server.

## Current infrastructure

- OS: Ubuntu Server 20.04
- Web server: Nginx
- HTTP: port 80
- SSH: port 22
- Git: GitHub

## What I have done

- Created Ubuntu Server virtual machine
- Configured network
- Initialized Git repository
- Created Git branches and commits
- Connected local repository to GitHub
- Installed Nginx
- Configured and launched web server
- Created custom HTML page
- Connected to Ubuntu Server via SSH
- Published the project to GitHub

## Architecture

Windows
↓
SSH :22
↓
Ubuntu Server
↓
Nginx :80
↓
HTML website
